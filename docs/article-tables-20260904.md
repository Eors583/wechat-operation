# 文章表格链路修复

## 支持边界

普通矩形表格：table > tableRow > tableHeader/tableCell > 块节点。
最多 200 行、20 列，当前不开放合并单元格或嵌套表格；非法结构明确拒绝，不能降级为普通段落并保存。
新增的 4 个 Tiptap 表格扩展固定为 2.27.2，与已安装编辑器同一版本；两个编辑入口复用同一扩展及表格菜单。

## 已修改环节

- AI 提示明确支持的表格结构及限制，沿用已有结构校验/一次修复机制。
- 后端 canonical 校验与 HTTP 请求/响应契约都接纳表格，并校验空行、不规则列、跨度及列宽。
- OpenAPI 导出和锁定快照更新；用户端、管理端类型由生成器更新，未手写 DTO。
- 前端 normalizeTiptapJson 和 HTML 转换不再把表格变成普通段落。
- 快速预览和正式编辑页支持插入、修改单元格、增删行列及删除表格。
- 后端最终排版输出 table/tr/th/td，单元格段落清除正文的大间距。
- 移动端由表格 wrapper 独立横向滚动，整页不溢出。

## 现有文章恢复

scripts/restore_article_table.py 默认 dry-run，只读取指定文章第 4 版中可完整解码的原表格。
仅当当前版本中的列表与原表格纯文本完全一致且匹配唯一时，替换这一块并创建新版本；不覆盖其他用户编辑。
已从第 5 版创建第 6 版，恢复 4 行 3 列表格；纯文本逐字一致，历史版本保留，聊天追加第 6 版入口。
数据库仍使用 Docker PostgreSQL，没有 schema migration。
