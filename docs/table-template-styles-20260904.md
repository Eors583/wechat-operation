# 表格模板样式

排版模板编辑器增加 table_header（表格表头）和 table_cell（表格单元格）模块，复用文字、背景、字号、字重、对齐、行距、内边距控件，并提供受控边框预设。
示例预览包含三列表格；文章快速预览、正式编辑页和最终 HTML 渲染读取相同的模板模块。

StyleProperties 增加 border_all，正则仅允许 none 或有限像素宽度、线型及六位十六进制颜色，禁止任意 CSS。
旧模板没有表格模块时，前后端使用一致的默认表头/单元格样式，无需修改数据库；配置保存为原有模板版本。
OpenAPI 已重新导出，用户端与管理端类型同步生成。

验证：模板控件修改、保存 payload、刷新读回、文章表格样式应用；1440×900、1280×720、1024×768、390×844 的 light/dark，无根页面横向溢出，移动端表格独立滚动。
脚本：apps/user-client/scripts/check-table-template.mjs 与 check-article-tables.mjs，全部使用拦截 API 的测试数据，不调用真实模型、不修改真实模板。
后端覆盖模板保存读回、最终 HTML 样式及 CSS 注入拒绝；前端单测、类型检查、lint/build 和管理端类型检查通过。
真实微信草稿/发布未调用，不把本地最终 HTML 检查等同于微信客户端发布验收。
